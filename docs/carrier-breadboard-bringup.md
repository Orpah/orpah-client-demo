# Carrier 面包板验证（bring-up）

按 `hardware/carrier/carrier-breadboard.fzz` 把载板电路**先在面包板上搭出来**跑通，
再去打板。这是 AGENTS §1 那条**开发次序**里的第 ② 步：

> **网表 → 面包板 → 原理图 → PCB**
> ① 网表 = `hardware/carrier/carrier_nets.py`（16 张网）
> **② 面包板 = 本图 ＋ 在实物上跑通（本文）**
> ③ 原理图 = `carrier-schematic.fzz`（已定稿 ✓）
> ④ PCB = `carrier-pcb.fzz`（已布线 ✓，等打板）

## 3. 三处**图上要看清楚**的地方

### 3.1 `BT1` 与 `SW1` 是**浮件**（板子下方，两根跳线接进板）

它们的脚距不是 2.54 mm，插不进面包板孔：

- `BT1` 脚距 **6.00 mm**（超容），图上浮在板子下方偏左，两根线分别是 `VBAT`（赭）与 `GND`（黑/灰）。
- `SW1` 的**面包板视图**虽然是 2.54 mm 间距，但**五只脚在同一排** —— 插进面包板就是**同一块 5 孔铜片**，
  等于把 1…5 全短在一起。所以图上按 `BT1` 的做法处理：**浮在板子下方偏右，只用两根跳线接 1、2 两脚**。
  其余三只（3/4/5）是**备用极**，悬空不用。

⇒ 搭的时候：把开关摆到板子旁边，用两根杜邦线接到对应孔即可；
**要临时替代开关**就用一根跳线短接 `3V3_IN` 与 `3V3` 那两颗孔（= 开关合上）。

### 3.2 `3V3_IN` 与 `3V3` 在图上**是两张网**（中间就是 `SW1`）

旧版图里有一根桥接线直接把这两张网并在一起（`bb_probe` 报「分量里有 `3V3` 与 `3V3_IN` 的脚 = 短接」）。
现在那根线已删，改成 `SW1`：

```
J4.4 OUTPUT ─┬─ J4.6 V_EN ─┬─ SW1.2 (COM)
J4.7 EN    ─┘              │
                            └─ SW1.1 → 板内 3V3（U1 VDD / U2 VCC / R1..R3 / J1..J3）
```

★ 注意 `V_EN`/`EN` 接在**开关前**（`3V3_IN` 侧）：开关断开时取能模块仍在工作，合上就上电。

### 3.3 导线颜色 = 网（图右侧的色条就是图例）

`GND` 黑 `#404040`、`3V3` 红 `#cc1414`、`3V3_IN` 赭 `#a37911`、`VBAT` 赭 `#a37911`、
`SDA` 蓝 `#418dd9`、`SCL` 棕 `#8c3b00`…… 全部取自 Fritzing 官方配色表的**面包板**那一节
（表在 `carrier_nets.py` 的 `COLOR`）。颜色**不是随便挑的**：表外的 hex 画出来对、但 Fritzing
指示栏认不出（会回落成"蓝"）。

## 4. 上电前：万用表逐条量（**先量后通电**）

断电、SW1 断开（或跳线未插）状态下，用万用表电阻/二极管档逐条量。**任一条不对就别上电。**

| # | 量哪里 | 应该是 | 不对说明什么 |
|---|---|---|---|
| 1 | `3V3` ↔ `GND` | **> 1 kΩ**（多数情况读数会随电容充电爬升） | < 100 Ω ⇒ 3V3 对地短路，先查有没有插错孔/引脚搭锡 |
| 2 | `VBAT` ↔ `GND` | 读数**从低往上爬**（超容在充电） | 一直是 0 Ω ⇒ `BT1` 短路或极性接反 |
| 3 | `BT1` 的 `+` ↔ `VBAT`、`-` ↔ `GND` | 各 **< 1 Ω** | 反了 ⇒ 超容反接（2026-10-17 原理图上出过这个错） |
| 4 | `SDA` ↔ `3V3`、`SCL` ↔ `3V3` | 各 ≈ **4.7 kΩ** | 无穷大 ⇒ 上拉没插；≈0 ⇒ 接错 |
| 5 | `U2` 的 `GND` ↔ `U1` 的 `VSS` | **< 1 Ω**（共地） | 不通 ⇒ SE 不会应答（现象是全部 NACK） |
| 6 | `J3.3` ↔ `U1` `PA13`、`J3.4` ↔ `U1` `PA14` | 各 **< 1 Ω** | 不通 ⇒ 烧不进去 |
| 7 | `3V3_IN` ↔ `3V3` | **断开**（开关 OFF / 没插跳线） | 通 ⇒ 开关焊/插错，或还留着旧的桥接线 |

## 5. 分级上电（每步都有判据，不对就停在那一层）

> 上电顺序刻意做成"一次只多接一样"，出错时能一眼看出问题在哪一层。

| 步 | 做什么 | 判据（**看到这个才算过**） |
|---|---|---|
| ① | 只给板子供电（`SW1` 合上 / 插跳线），**不插模组、不接前端** | 板载心跳灯 **`PB0`**：上电先闪 3 下，然后 **1 Hz** 持续闪；`3V3` 实测 **3.3 V ± 5 %** |
| ② | `J2.5`/`J2.6`（`CON_TX`/`CON_RX`）+ `J2.2`（`GND`）接 USB-UART，**115200 8N1** | 控制台出**启动横幅**：能读到 `se_hw` / `se_ok` / `nonce_src` 那几个字段 |
| ③ | 控制台敲 `se` | ATECC608B 应答：`Random` 回 32 字节、`Sign(slot 0)` ok（**全 NACK 就回 §4 第 5 条**） |
| ④ | 插模组到 `J1`（`3V3`/`GND`/`MOD_RX`/`MOD_TX`），敲 `idlevel l0` 再 `idsend` | 模组口出 `[mbus rx] … byte(s)`；本板 SE 签名 ⇒ 报文字段 `nonce_src=se sign_src=se` |
| ⑤ | 接前端（`J4` 插 `CJMCU-2557`），`SW1` 保持断开先量 | `3V3_IN` ≈ **3.3 V**（模块已工作）、`VBAT` 电压**随时间上升**（超容在充）；合上 `SW1` ⇒ `3V3` 起来、心跳灯亮 |

★ 第 ①/② 步就不过（灯不闪、串口全静默），**先怀疑烧录/时钟/启动**，不要急着查电路：
烧完**不会自动运行**，必须**断电再上电**或按一次 `RST`。

## 6. 烧录（载板档）

```bash
cd firmware
make rebuild BOARD=carrier      # 心跳灯 PB0、SE 走 I2C2（PB10/PB11）
```

- `BOARD=carrier` 与台架档（`BOARD=bench`，默认）**只差两处**：心跳灯 `PA15`→`PB0`、SE 的 I2C1→I2C2
  （`CH32V203F8U6` 封装上 `I2C1` 没引出 ⇒ 载板只能用 `I2C2`）。
- WCH-LinkE **只接三根**：`CLK → J3.4`（`SWCLK`）、`DIO → J3.3`（`SWDIO`）、`GND → J3.2`。
  **`3V3` 不要接**（板子自己供电；两边同时供电容易顶）。
- 烧完按一次 `RST` 或断电重上电。

## 7. 图上"看得见但要想一下"的两处

1. **`U1` 的裸露焊盘 `VSS`** 在图上是一只**接线的脚**（不是插孔）—— 实物要么靠转接板把它引出来，
   要么在 GND 轨上用一根线接到它（PCB 上它是 EPAD → 散热过孔 → 背面地铜）。
2. **`SW1` 的备用极（3/4/5）既没插孔也没接线**，所以 `bb_precheck.py`（**布线前**的摆位闸门）
   会报「`SW1.connector2/3/4` 没落到孔上」。这是**设计如此**，不是图错了 ——
   本图的判据是 `bb_probe.py`（网表闸门）✓ 全过。

## 9. 边界（如实）

- **本文所有判据都还没在实物上量过** —— 图与网表是机器核过 ✓（§1），电路是否真的按预期工作
  要按 §4/§5 一条条搭起来才知道。
- 图上 `BT1` / `SW1` 是**浮件**（§3.1），所以"图上连线"与"手上两根杜邦线"必须一一对上：
  **接错一根 = 极性反 / 开关不串在中间**，量 §4-2 / §4-7 就能发现。
- `bb_probe` 只看 `<connect>` 与 `<buses>`，**不看几何**：它证明"该连的连了、没短接"，
  **不证明**"线没有压在别的孔上"。线压在孔上属物理插拔问题，只能靠人看着搭。
