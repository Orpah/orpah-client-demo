> 对应 SPEC **F-11「真机标定数值」**（**未做** ✗）与规格 §4c「测电流做成板上标配」✓。
> 目的只有一个：把 `orpah-over-halow` 能量模型里那几个**演示值**换成**实测值** ✓。
> **模型本身不改** ✗ —— 只换喂给它的数（`energy.py` 的三个参数 ＋ `energy_calib.py` 的 8 个可标定项 ✓）。

## 1. 量什么 = 模型的哪个字段（一一对应，**别自创名字** ✗）

| # | `energy_calib` 字段 | 单位 | 物理含义 | 怎么得到 |
|---|---|---|---|---|
| 1 | `sleep_mw` | mW | 待机（MCU + SE 醒着、**模组睡着**、不发报）的平均功率 | **量**：主轨跳线串电流表，静置 60 s 取平均 ⇒ ★ **模组睡没睡**就体现在它上面（见 §2b ②-2 ✓） |
| 2 | `cost_es256` | mJ | **一轮 ES256 上报**的总能耗（含模组唤醒 ＋ 发射 ＋ 收听） | **量**：§2 方法 A ＋ **必须让模组真睡** ✓（见 §2b ②-3 ✓） |

| 4 | `listen_mj` | mJ | **听一次下行**的代价（模组接收窗口） | **量**：要空口对端配合（AP 发一帧 ✓）—— **没模组时量不了** ✗ |
| 5 | `store_mj` | mJ | 储能可用容量 | **算**：超容 `½·C·(V₁²−V₂²)` —— ★ 窗口按 **BQ25570** 算：上限 `VBAT_OV` **5.0 V** ✓、**可用下限 ≈3.5 V**（**3V3 轨压差** ✗，**不是** 1.95 V ✗）⇒ 见 `carrier-board-spec.md` §4b-2 ✓；**锂电不装** ✗（用户 2026-10-13 ✓） |

## 2. 两种量法（板上的跳线就是为这个留的 ✓）

### 方法 A（推荐，最省仪器）：储能电压跌落法
1. 让板子只由**储能**供电（主轨跳线断开、不接取能 ✓）；
2. 固件进入常态（每 60 s 一报 ✓），**跑 N = 20 报**；
3. 记**前后**储能电压 `V₁` / `V₂`（储能测试点 ✓）⇒
   `cost = ½·C·(V₁² − V₂²) / N`（`C` = 实测容量 ✓）。
   ⇒ 这给的是**平均**，**看不出峰值** ✗；适合 `cost_es256` / `cost_hs256` / `sleep_mw` ✓。

### 方法 B（要看峰值就得它）：分流电阻 + 示波器
1. 主轨（或模组支路）跳线处串一只**已知小阻值**分流电阻（0.1 Ω / 1% ✓）；
2. 差分测它两端电压 ⇒ 电流包络；对**一次上报**积分 = `cost_*` ✓；
3. 顺便看两件**决定成败**的事 ✗：模组发射瞬间的**电流峰值** ＋ 3V3 轨的**压降** ✓。

### 判据（两个数都要过 ✓）
- **平均**：`取能可用功率 ≥ 待机 ＋ 上报 ＋ 监听开销`（= `energy.plan()` 里的 `usable` ⇒ `tier = ok` ✓）；
- **峰值**：发射瞬间 3V3 压降**不低于模组的最低工作电压** ✗（具体值查泰芯手册 ✓）＋ **MCU 不复位** ✓。

## 2b. 模组侧三条量法（前端定 `BQ25570` 后必须补的 ✓）

起因 = 规格 §4b-2 的结论：buck 只有 **93～110 mA 连续**能力 ✓ ⇒ **峰值必须靠电容顶** ✗、
**平均要靠占空比压** ✓ ⇒ 下面三条**得分开量** ✗（拿一个"整板平均电流"什么都定不了 ✓）。

### ②-1 发射峰值电流 `I_pk` 与持续时间 `t_burst`（定 3V3 轨的电容 ✓）
- 量法 = **方法 B**（分流 ＋ 示波器 ✓）；分流电阻串在**模组 VCC 支路** ✓（✗ **不是**整板 ——
  整板会把 MCU 那几十 mA 混进来 ✗）；
- 触发：固件 `idsend` 发一帧 ✓ ⇒ 看**单次发射包络** ⇒ 读 `I_pk` 与 `t_burst` ✓；
- 同一时刻用第二通道读 **3V3 轨** ✓ ⇒ 得**实测的** `ΔV` ✓（不靠假设 ✓）；
- ★ 按 `AT+TXPOWER` **扫档**（手册范围 **6～20 dBm** ✓）：峰值与压降都随功率变 ✗ ⇒ 记录里写清哪档 ✓
  （降一档 TX 功率 = 直接省电容/省能量的一条旋钮 ✓，代价是距离 ✓）。
- ⇒ 判据：`C_needed = (I_pk − 100 mA)·t_burst / ΔV_allow` ✓（表见规格 §4b-2 ✓）⇒ 定 3V3 轨电容 ✓。

### ②-2 常驻（关联 / 接收）电流（定"能不能睡、睡多深" ✓）
- 量法 = **方法 A 的镜像** ✓：只用储能、**不发报**，静置 60 s × N 次，读储能电压跌落 ⇒ 平均功率 ✓；
- ★★ **要按 `AT+PS_MODE` = 1 / 2 / 3 / 4 各量一遍** ✓（模式定义见 `T-Halow-RJ45/docs/AT_cmd.md` ✓：
  0/3 = 只保 AP 连接、**任何单播可唤醒** ✓；2 = 保活交给 AP（**最低功耗** ✓）；
  ★ 4 = **只能被 AP 的 `AT+WAKEUP` 唤醒** ✗）；
- ⚠ **模式 4 的唤醒权在 AP 手里** ✗ ⇒ "**设备自己定时醒来发报**"这条路**能不能走**要单独确认 ✓
  —— 那是**功能**问题、不只是电流 ✗（先试 3，再试 4 ✓）；
- 命令：`AT+DSLEEP=1` 进休眠 ✓（`halow-demo` 2026-09-07 实测 ✓：连接态保活休眠、
  **链路保持、AT 仍可用**、AP 侧 `AT+WAKEUP=<mac>` 能唤醒 ✓）；
  ⚠ **非连接态的深度休眠未测** ✗（当时记录"可能睡到要物理重插"✗）⇒ 别拿它当基线 ✗；
- ⇒ 量出的数**落到哪个字段**：模组睡着时的残余 → **`sleep_mw`** ✓；保持关联/接收那一段 → **`listen_mj`** ✓
  （✗ **不新增字段**，模型不改 ✓）。

### ②-3 一次"唤醒 → 上报 → 收下行 → 回睡"的能量（= `cost_es256` ✓）
- 量法 = **方法 A** ✓（`½C(V₁²−V₂²)/N` ✓），★ 但**必须让模组真的睡** ✓ —— 否则量到的是
  "常驻电流占大头"的假数 ✗；
- ⇒ 同一条件下**再量一遍"不休眠"** ✗（对照 ✓）：两个数应当**差得显著** ✓（差不出来就说明没睡成 ✓）
  —— 差值 = **休眠带来的收益** ✓，直接回答"必须让模组睡"这句结论到底值多少 ✓。

## 4. 仪器与前置

- 万用表（µA 档 / mV 档 ✓）、**示波器**（要看 µs 级包络 ⇒ 带宽要够 ✓）、分流电阻（0.1 Ω 1% ✓）、
  稳压源或充满的储能 ✓、能读储能电压的测试点 ✓。
- ★ 模组那三条（§2b）还要：分流电阻**串在模组 VCC 支路** ✓（不是整板 ✗）、示波器**两通道**
  （一通道看分流、一通道看 3V3 ✓）、能下 `AT+PS_MODE` / `AT+DSLEEP` 的模组控制台 ✓、
  AP 侧能发 `AT+WAKEUP` ✓。
- ★ **BQ25570 模块（CJMCU-2557）自己也是量具** ✓：它是"输入→储能，输出 3V3"的完整前端 ⇒
  把储能换成**已知容量**的超容/电解电容就能当库仓计用 ✓（但它自己的 `VOUT`/`VBAT_OV` 设定
  **先核** ✗，见规格 §4b-2 ✓）。
- ⚠ **别拿台架上的 5V/3V3 当"取能"** ✗ —— 这一步量的是**载板 + 储能**，不是台架 ✗。

## 5. 边界（别把结论说大 ✗）

- 量的是**我们这块板**（含模组峰值 ✓），**不含**空口路径损耗 / 服务端 ✓；
- 一次标定只对**当时的储能、模组固件版本、上报间隔**成立 ✓ ⇒ 换板 / 换固件 / 改间隔都要重标 ✓。
- ★ 模组侧的结论**必须带两个前提** ✗：① **`AT+PS_MODE` 是哪个模式** ✓（模式 4 只能被 AP 唤醒 ✗
  —— 不只影响电流，还影响"设备能不能自己定时醒来上报"✗，那是**功能**问题 ✓）；② **哪个固件版本** ✓
  （台架上见过的是 `v2.4.1.5` ✓）。
- ⚠ 休眠**已实测的只有"连接态保活休眠"** ✓（`AT+DSLEEP=1`，`halow-demo` 2026-09-07 ✓）；
  **非连接态的深度休眠未测** ✗ ⇒ 别拿它当省电基线 ✗。
## 6. 操作单（上机那一趟：照着做 ✓）

### 6.1 接线怎么改（在现有台架上改，别动别的 ✗）
1. **把模组的供电从它的 USB 上拿下来** ✗ —— 改由台架电源**经分流电阻**供 ✓（不拿下来就量不到电流 ✗）。
   ⚠ **先看 TX-AH EVB 的原理图**，找一个**可断的点** ✓（能在模组 VCC 那一侧断最好 ✓）；
   **记下你断的是哪里** ✓（写进记录表的「条件」格 ✓，下次要复原 ✓）。
2. **分流电阻串在低端**（模组 `GND` 与系统地之间 ✓）⇒ 示波器**单端**就能看 ✓（不用差分探头 ✓）；
   代价 = 模组的地被抬 `I×R` 那么点（0.1 Ω × 300 mA = **30 mV** ✓ 无害 ✓）。
3. 阻值 **0.1 Ω / 1% / ≥0.25 W** ✓ ⇒ 换算 **1 mV = 10 mA** ✓（好读 ✓）。
4. 示波器：**CH1** 看分流两端 ✓、**CH2** 看 **3V3 轨** ✓；两通道地接同一参考点 ✓；
   触发 = **CH1 上升沿、单次（single）** ✓。
