# 载板 F-11 实测计划：电流/能耗怎么量、量到哪

> 对应 SPEC **F-11「真机标定数值」**（**未做** ✗）与规格 §4c「测电流做成板上标配」✓。
> 目的只有一个：把 `orpah-over-halow` 能量模型里那几个**演示值**换成**实测值** ✓。
> **模型本身不改** ✗ —— 只换喂给它的数（`energy.py` 的三个参数 ＋ `energy_calib.py` 的 8 个可标定项 ✓）。

## 1. 量什么 = 模型的哪个字段（一一对应，**别自创名字** ✗）

| # | `energy_calib` 字段 | 单位 | 物理含义 | 怎么得到 |
|---|---|---|---|---|
| 1 | `sleep_mw` | mW | 待机（MCU + SE 醒着但不发报）的平均功率 | **量**：主轨跳线串电流表，静置 60 s 取平均 |
| 2 | `cost_es256` | mJ | **一轮 ES256 上报**的总能耗（含模组发射） | **量**：§2 两种方法（推荐 A：电压跌落法） |
| 3 | `cost_hs256` | mJ | 一轮 HS256（降级腿）上报的总能耗 | 同上，`idlevel l1` 后再量一遍 |
| 4 | `listen_mj` | mJ | **听一次下行**的代价（模组接收窗口） | **量**：要空口对端配合（AP 发一帧 ✓）—— **没模组时量不了** ✗ |
| 5 | `store_mj` | mJ | 储能可用容量 | **算/查**：超容 `½·C·(V₁²−V₂²)` ＋ 电池（标称 × 实测内阻 ✗） |
| 6 | `charge0_mj` | mJ | 上电时的初始电量 | **量**：上电瞬间储能电压 → 换成能量 |

## 2. 两种量法（板上的跳线就是为这个留的 ✓）

### 方法 A（推荐，最省仪器）：储能电压跌落法
1. 让板子只由**储能**供电（主轨跳线断开、不接取能 ✓）；
2. 固件进入常态（每 60 s 一报 ✓），**跑 N = 20 报**；
3. 记**前后**储能电压 `V₁` / `V₂`（储能测试点 ✓）⇒
   `cost = ½·C·(V₁² − V₂²) / N`（`C` = 实测容量 ✓）。
   ⇒ 这给的是**平均**，**看不出峰值** ✗；适合 `cost_es256` / `cost_hs256` / `sleep_mw` ✓。

### 方法 B（要看峰值就得它）：分流电阻 + 示波器
1. 主轨（或模组支路）跳线处串一只**已知小阻值**分流电阻（0.1 Ω / 1% ✓）；
2. 差分测它两端电压 ⇒ 电流包络；对**一次上报**积分 = `cost_*` ✓；
3. 顺便看两件**决定成败**的事 ✗：模组发射瞬间的**电流峰值** ＋ 3V3 轨的**压降** ✓。

### 判据（两个数都要过 ✓）
- **平均**：`取能可用功率 ≥ 待机 ＋ 上报 ＋ 监听开销`（= `energy.plan()` 里的 `usable` ⇒ `tier = ok` ✓）；
- **峰值**：发射瞬间 3V3 压降**不低于模组的最低工作电压** ✗（具体值查泰芯手册 ✓）＋ **MCU 不复位** ✓。

## 4. 仪器与前置

- 万用表（µA 档 / mV 档 ✓）、**示波器**（要看 µs 级包络 ⇒ 带宽要够 ✓）、分流电阻（0.1 Ω 1% ✓）、
  稳压源或充满的储能 ✓、能读储能电压的测试点 ✓。
- ⚠ **别拿台架上的 5V/3V3 当"取能"** ✗ —— 这一步量的是**载板 + 储能**，不是台架 ✗。

## 5. 边界（别把结论说大 ✗）

- 量的是**我们这块板**（含模组峰值 ✓），**不含**空口路径损耗 / 服务端 ✓；
- 一次标定只对**当时的储能、模组固件版本、上报间隔**成立 ✓ ⇒ 换板 / 换固件 / 改间隔都要重标 ✓。
