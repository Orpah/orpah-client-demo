# b 步夹具接线图：CH347F-EVT ↔ TX-AH EVB

本目录放 **b 步（PC ↔ TX-AH 模组）台面夹具的接线图** —— 一张 Fritzing 工程 + 它的 SVG 导出。
文字版接线表在 [`../../docs/txah-uart-macbus.md`](../../docs/txah-uart-macbus.md) §3（单块）与
§7（两块模块端到端）；本文件是那份表的**图版**。

| 文件 | 说明 |
|---|---|
| `bstep-ch347f-txah-evb.fzz` | Fritzing 工程（可编辑）。**内嵌**用到的两个部件，自包含 |
| `bstep-ch347f-txah-evb.svg` | 同图的 SVG 导出（文档里直接看，不必装 Fritzing） |

## 接线（从 `.fzz` 里抽出来的真实连线，2026-09-16）

| TX-AH EVB（`U2` = `TX-AH-R900PNR_rev_1`） | CH347F-EVT（`U3` = `CH347F`） | 线色 |
|---|---|---|
| `A10` = 模组 UART0 **RX**（模组收） | **`TXD0`**（CH347F UART0 TX = `P2`） | 蓝 `#418dd9` |
| `A11` = 模组 UART0 **TX**（模组发） | **`RXD0`**（CH347F UART0 RX = `P2`） | 绿 `#25cc35` |
| `A13` = 模组 UART1 TX（AT/打印口） | **`RXD1`**（CH347F UART1 RX = `P3`） | 橙 `#ef6100` |
| `A12` = 模组 UART1 RX | **`TXD1`**（CH347F UART1 TX = `P3`） | 紫 `#ab58a2` |
| `VCC`（模组板 3.3V） | `VIO`（CH347F I/O 参考） | 红 `#cc1414` |
| `GND` | `GND` | 棕 `#8c3b00` |

- **一个 CH347F 同时管两端**：`P2`（UART0）走模组**数据口**，`P3`（UART1）走模组 **AT/打印口**
  ⇒ PC 上一个进程发数据、另一个口看日志；脚本里的 `--ch347f-com 0` / `--ch347f-com 1` 就是这两路。
- 方向口径（别接反）：`TXD0 → A10`、`A11 → RXD0`；`TXD1 → A12`、`A13 → RXD1`。
  模组侧 A10=UART0_RX / A11=UART0_TX 的出处见 `../../docs/txah-uart-macbus.md` §5.1。
- 图上 `A10/A11/A12/A13/GND/VCC` 都是 `TX-AH-R900PNR_rev_1` 里 **J4/J5 跳线区的焊盘**
  （各自独立网：它们与模组 38 个边脚**实测不通**，所以没有并成一条总线）。

## 用到的部件版本（重要）

`.fzz` 会把用到的部件**连图形一起打包**，所以这个文件自身就够复现一张同样的图。本图用的是：

- `TX-AH-R900PNR_rev_1` —— **带 J4/J5 可接线**的那版（原版 `TX-AH-R900PNR` 的 J4/J5 焊盘没有 connector，
  画不出这张图）；
- `CH347F`。

两者都来自 `fritzing-parts-langhua` 仓的 `fzpz/`。

> ⚠ 因为是**快照**：部件以后改版，这张图**不会自动跟着变**。要跟上就重新导入部件、重画连线再存一次；
> 反过来说，这也是它的优点 —— 这张图能把"当时那版"完整冻住。

## 怎么用

- **看/改**：Fritzing 打开 `.fzz`（本图由 Fritzing 1.0.3b 保存）。
- **文档里引用**：用 `.svg` 就行（别人不必为了看这张图去装 Fritzing）。
- 图里那个 `PCB1`（空白矩形 PCB）没有任何连线，是装饰/占位，删掉不影响接线。

## 边界（如实）

- 这张图记录的是**这套台面夹具怎么接**，不等于链路已验证。截至 2026-09-16 的实测进度见
  `../../docs/txah-uart-macbus.md`：**控制面（命令/事件）已通**（`send-cmd 43` 有回包），
  **数据面端到端待两块模块实测**（§7）。
- `模组 VCC → CH347F VIO` 这一根：`CH347F` 部件里 `VIO` 是**独立总线**（不在 `3V3`/`VCC` 轨上），
  图上这么接 = 拿模组板的 3.3V 当 CH347F 的 I/O 电平参考。
  **建议对一下 CH347F-EVT 原理图**，确认 `VIO` 是"输入参考"还是"输出轨"；
  我们的既有口径是「共地必须接、**别用 CH347F 的 3V3 去带模组**」（见 `../../docs/txah-uart-macbus.md` §3.3）。
- 图上只有"接线"，**没有**画：模组/CH347F 各自的 USB 供电与 USB 线（刷机、看日志用）、
  以及调试时要**拔掉 TF 卡**、**J5 跳线帽拿掉**这两条环境项。
